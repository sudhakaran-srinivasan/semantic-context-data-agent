# Team and workflow

## Communication

- Slack channel for updates and all day-to-day communication.
- GitHub for code and tracking (Issues + a Projects board).
- Async-first: short written updates, handoff notes at the end of each person's day. One short weekly sync.
- One teammate is in Japan time (JST) from Nov 11; another is on US Eastern or Pacific time. Plan any live meeting a few days ahead.

## Working agreements

- Small pull requests; one reviewer.
- Never commit secrets. Use `.env` (ignored) and update `.env.example` when a new variable is added.
- Every prompt change gets a changelog line in `prompts/`.
- Log AI-tool use in `docs/ai-use-log.md`.

## Scope guardrails

- One small local database (DuckDB), generated by a seeded script so everyone gets identical data.
- A hand-written YAML semantic layer, not a catalog or a graph database.
- About 20-30 test questions, including cases where the correct behavior is to clarify or decline.
